# math

動かして確かめる数学のインタラクティブなWebアプリです。25のテーマをタブで切り替えます。

**公開URL: https://htanny.github.io/math/**

タブは4つのグループに分かれています。

- **小学校** — 手続きだけ覚えて終わりがちなところを、意味に戻して見る
- **中学校** — 動かすこと自体が証明になるもの
- **高校** — 概念そのものを作り替えるもの
- **数の探検** — 未解決問題や、単純な規則から複雑な構造が現れる例

# 小学校

### 1. 分数の割り算（小6）
「なぜひっくり返して掛けるのか」。`2/3 ÷ 1/4` を「2/3 の中に 1/4 がいくつ入るか」として
タイルで数えると、答えが 8/3 になる理由が見えます。

- 分子・分母を自由に変えられる面積図。入りきらない最後の1枚は、入ったぶんだけ色分け。
  使えない値（0 や空欄）を入れたときは、代わりに使った値を明示します —— 図と入力欄が食い違ったままになりません
- **かぎは「1 の中にわる数がいくつ入るか」** — その個数がちょうど逆数になっている
- 逆数を掛ける式変形を4行で提示。答えは既約分数と帯分数の両方で表示

### 2. 割合と速さ（小5〜6）
「もとにする量」がどれか分からなくなる、小学校算数最大の難所。

- **二重数直線**: 上が量、下が割合。求めるものを選ぶと残り2つから計算され、
  「割合の 1 の真上が、もとにする量」が図から読めます。歩合（○割○分）も併記
- **ダイヤグラム（旅人算）**: 出会い算・追いつき算・往復の3問。速さをスライダーで変えると
  線の傾きが変わり、交点＝出会う瞬間が動きます（既定値では 15 分・12 分・10/30 分で交わります）

### 3. 円の面積 πr²（小6）
円を扇形に切って交互に並べかえると長方形に近づく、あの説明。

- 扇形が**1枚ずつ順に**並べかわるので、途中の図も「切りかけの円＋できかけの長方形」として読めます
- よこが分割数によらずいつでも πr であること、変わるのは形のほうであることを明示
- 弧を弦に置きかえた内接多角形の面積の収束表（n を倍にすると誤差がおよそ 1/4）

### 4. 展開図と立体（小4〜6）
平らな展開図が折り上がって立体になるアニメーション。立方体・直方体・三角柱・正四面体・四角錐。

- 折りぐあいと見る向きをスライダーで操作。面ごとに色分けし、どの辺がくっつくかを追えます
- 頂点 V・辺 E・面 F と **V − E + F = 2**（オイラーの多面体定理）を表示。
  これらは折りあがった立体の座標から数えた実測値で、表から引いた値ではありません

### 5. 立体切断（中学受験）
中学受験の最難関。むずかしいのは切り口の形そのものより、**作図の3原則の3つめ
「面を延長して、立方体の外に交点をつくる」**です。紙の上では何が起きているのか分からない操作を、
回して確かめられるようにしました。

- 立方体 ABCD-EFGH の辺の上に3点を置くと切り口が出ます。ドラッグで自由に回転、真上／真正面の固定ビューつき
- **1本ずつ引ける**: 各線が3原則のどれで引かれたかを順に表示。原則3のときだけ延長線と
  立方体の外の交点が明るくなります
- 切り口を**2つに離して**見られます
- 切り口の形を判定（正三角形・長方形・ひし形・等脚台形・正六角形…）、面積、体積比を
  **7 : 17 のような整数比**で表示
- 例: 6辺の中点を通る正六角形（体積をちょうど二等分）／頂点を切り落とす（1 : 5）／
  延長法が要る五角形（25 : 71）／等脚台形（7 : 17）
- **角柱の斜め切り**の別パネル: `体積 = 底面積 × 側面の辺の平均` が本当に合うことを、
  実際に切って求めた体積と並べて確認できます。四角柱では4本目の辺が自由に決められない理由も出ます

### 6. 動きとグラフ（中学受験）
答えが数ではなく**グラフの形**で問われるタイプ。どこで折れるのか、どこが直線でどこが曲線なのか。
紙の上では図が止まっているのが最大の難所なので、動かしながらグラフが描かれていく形にしました。

- **重なりの面積**: 動く図形が毎秒 1cm で通り過ぎ、共通部分の面積が下のグラフに描き足されていきます。
  折れ点はボタンで一発ジャンプでき、各区間が直線か曲線かと1秒あたりの増減を表示
  - 正方形×小さい正方形（台形のグラフ）／同じ大きさ（平らな部分がなく三角形になる）／
    直角三角形（横はばと高さが同時に変わるので**曲線**）／L字（傾きが 5 → −2 → −3 と3回変わる）
  - へこんだ図形は凸な部分に分けてから重なりを求めています
- **水そうグラフ**: 仕切りのある水そうに一定の割合で水を入れ、左のへやの水面の高さをグラフに。
  グリッド線を**仕切りの高さに置いてある**ので、グラフが平らになる位置と一致するのが見えます
  - 区間ごとの表つき（例: 仕切り2枚だと 0→16→28→42→60→90 秒の5区間）。
    のぼる区間の傾きが「毎秒の水量 ÷ そのとき水を受けている底面積」であることを数値で確認できます

# 中学校

### 7. 一次関数と連立方程式（中2）
連立方程式の解は2直線の交点。だから平行なら解なし、重なれば解は無数。

- 傾きと切片のスライダーで2直線を動かし、交点・平行・一致を切り替え
- **加減法の計算過程**を整数係数の入力から自動生成。答えは分数のまま
  （片方の式に y がない場合など、そろえる必要のないケースも別扱い）

### 8. 確率と大数の法則（中2）
サイコロ1個 / 2個の和 / コインを、1回から10万回まで。

- 相対度数の棒グラフに理論値を重ねて表示
- 対数目盛の収束グラフ — 左端の暴れ方と右端の落ち着き方の対比
- **相対度数は 0 に近づくが、回数のずれはむしろ大きくなる**（およそ √回数）ことを併記。
  「そろそろ出ていない目が出るはず」がなぜ誤りかが、2つの数字を並べると分かります

### 9. 円周角の定理（中3）
円周上の点 P をどこへドラッグしても、弦 AB を見込む角 ∠APB は変わりません。動かすこと自体が定理の実感になります。

- A・B・P すべてを円周上で移動可能（ドラッグ、または動かす点を選んで矢印キー）。P の軌跡を残して「どこでも同じ角」を可視化
- 中心角がつねに円周角の 2 倍であることを実測値で表示（P が劣弧側に回ると中心角は優角側に切り替わる）
- 「AB を直径にする」でタレスの定理（円周角 90°）
- 反対側の弧に点 Q を置くと、円に内接する四角形の対角の和が 180° になることを確認できる

### 10. 三平方の定理（中3）
`a² + b² = c²` を、面積を動かして見せる2つの証明。どちらも**動かしているあいだ面積が変わらない**ことが要です。

- **組みかえ**: 一辺 a + b の正方形に同じ直角三角形を4枚。置き方を変えると、あいた場所が
  a² と b² から c² ひとつに変わります。三角形は**回転も裏返しもせず平行移動するだけ**で、
  1枚ずつ順に動くので追えます
- **ユークリッドの等積変形**: 脚の上の正方形を、せん断 → 真下へ平行移動 → 縦にせん断 の
  3手で斜辺の正方形へ流し込みます。スライダーをどこで止めても表示面積は b²・a² のまま
  （面積が全フレームで厳密に保たれることは `scripts/verify-pythagoras.mjs` で検証しています）

# 高校

### 11. 単位円と三角関数（数学I・II）
単位円上を回る点の高さが、そのまま sin のグラフとして横に描かれていきます。円とグラフを点線で結んであるので、両者が同じものだと目で追えます。

- θ スライダーと1周アニメーション、sin / cos / tan の表示切替
- tan は x = 1 の接線上の線分として表示
- 0°・30°・45°・60°… のプリセットで暗記すべき厳密値を表示
- `y = A sin(B(x − C)) + D` のスライダー（振幅・周期・平行移動が文字とどう対応するか）

### 12. 微分と積分（数学II・III）
微分＝接線の傾き、積分＝符号付き面積、そして「面積を微分すると元に戻る」を同じ関数の上で連動させています。

- 割線を h → 0 で接線に近づけるアニメーション。導関数のグラフを下段に同時表示
- **増減表とグラフの概形**: f / f′ / f″ を縦に並べ、極値と変曲点を自動検出してマーク。増減表は3つのグラフから自動生成
- **平均値の定理**: 両端を結ぶ割線に平行な接線を持つ点 c を自動で見つけて描画（複数あればすべて）
- 区分求積：短冊の数 n と高さの取り方（左端／中点／右端）。x軸より下の短冊は**負として色分け**
- 面積関数 S(x) の x = b での接線の傾きが f(b) の高さと一致することを表示
  —— 微積分学の基本定理 S′(x) = f(x) の可視化

### 13. 微分を深める（数学II・III）
公式として暗記されがちなところを、意味に戻して見ます。

- **微分できない点**: `|x|`（尖点）・`√|x|`（垂直接線）・`x sin(1/x)`（振動）・`x² sin(1/x)`（微分可能）を、
  左右の割線の傾きが同じ値に近づくかどうかで判定。h を縮めた表付き
- **定義から導関数を求める**: `lim (f(x+h) − f(x))/h` の式変形を1行ずつ表示。約分の一行を強調し、
  「約分した式の値」と「差分商の値」が一致することを数値で並べて確認
- **積の微分を面積で見る**: 長方形が右と上に伸びて増える3つの部分。角の `df·dg` が全体の何%かを表示し、
  dx を縮めると 0 に向かうのが見える
- **連鎖律**: x → u → y の3本の数直線を連動させ、Δx・Δu・Δy の幅を比較。変化率が掛け算になる理由

### 14. 微積の発展（数学II・III）
微積が何の役に立つのか。

- **テイラー展開**: sin / cos / eˣ / log(1+x) / 1/(1−x) を次数0〜17で近似。
  主指標は「一致する範囲（誤差0.01未満）」で、次数とともに単調に広がる。
  収束半径が有限な関数では**いくら次数を上げてもその範囲を超えない**ことも見える
- **ニュートン法**: 接線と x軸の交点を次の点に。誤差の桁がおよそ倍々になる2次収束を表で提示
- **回転体の体積**: 円盤を積み上げて `V = ∫π f(x)² dx` に近づける。球・円錐・放物面・ビーズ形
- **e はどこから来たのか**: `aˣ` の底を動かし、x=0 での接線の傾きがちょうど 1 になる a を探す。
  `(1+1/n)ⁿ` の表も併記

### 15. 円錐を切ると（数学C）
楕円・放物線・双曲線は、別々の式をもつ3つの曲線として習います。本当は**ひとつの円錐を3通りの角度で
切っただけ**で、どれになるかを決めているのは「切る平面が円錐の側面よりゆるいか、ちょうど平行か、急か」だけです。

- 上下2つに広がる円錐を平面で切り、切り口を3Dで表示。ドラッグで回転。
  傾き ψ・半頂角 α・切る高さのスライダーと、傾きを 0° から自動で上げていく再生ボタン
- **切り口を正面から見た本当の形**を別パネルに。焦点を打ち、点 P を動かすと
  **2つの焦点までの距離の和（双曲線なら差）が変わらない**ことが数値で確かめられます。
  教科書で別々に習う「焦点の定義」と「円錐の切り口」が、ここで同じものになります
- 離心率が `sin ψ ÷ cos α` に等しいこと（楕円 < 1、放物線 = 1、双曲線 > 1）を表示。
  切る高さを変えても大きさが変わるだけで種類は変わりません
- 「細い円錐で楕円」の例つき —— 同じ 60° でも α=30° なら放物線、α=18° ならまだ楕円。
  決めているのは傾きそのものではなく**円錐の側面と比べてどうか**だと分かります

### 16. 複素数平面（数学C）
複素数を掛けるとは、回転して伸ばすということ。`|zw| = |z||w|`、`arg(zw) = arg z + arg w`。

- z と w を動かすと積 zw が追従（ドラッグ、または動かす点を選んで矢印キー）。実部・虚部・絶対値・偏角を表で確認できます
- w を単位円上に固定すると、掛け算が**純粋な回転**になります
- 1 の n 乗根が正 n 角形の頂点に並ぶ様子と、|z| を 1 からずらしたときの累乗のらせん

### 17. 中心極限定理（数学B）
釘に当たって左右にはねるだけのボールが、積み上がると釣鐘になる。

- **ゴルトンボード**: 段数を変えて 1 個ずつ / 1000 個まとめて。二項分布と正規分布の重ね描き。
  平均と標準偏差を理論値（n/2、√n/2）と並べて表示
- **標本平均の分布**: 一様 / サイコロ / 二山 / 指数 のどれを選んでも、n を増やすと釣鐘になり、
  幅は σ/√n に縮みます。上下のグラフが**同じ横軸**なので、縮んでいく様子がそのまま見えます

# 数の探検

### 18. コラッツ予想（3n+1問題）— 未解決
偶数なら2で割り、奇数なら3倍して1を足す、を1に到達するまで繰り返します。

- 数列が1ステップずつ進む様子をアニメーション表示（現在値・ステップ数をリアルタイム更新）
- 完了時にステップ数・最大値・最大値到達ステップを表示
- 最大3系列の比較表示、対数スケール切替、ホバーツールチップ
- 1〜指定上限のうちステップ数の記録を更新した開始値を棒グラフで探索

### 19. アリコット数列（カタラン・ディクソン予想）— 未解決
その数の「自分自身を除く約数の和」を繰り返します。1に到達するか、循環するか、
無限に大きくなり続けるか — 276 は2000項以上・200桁を超えてもなお決着していません。

- 終わり方を自動判定: 1に到達 / 完全数（1周期）/ 友愛数（2周期）/ 社交数（3周期以上）/ 未決着
- 循環に入った場合はその循環を表示（例: `220 → 284 → 220`）
- 1〜指定上限の各整数を「行き着く先」で分類して集計
- 値が 10<sup>12</sup> を超えた場合・260ステップに達した場合は打ち切り、その旨を明示

### 20. ロジスティック写像
`x → r·x(1−x)` というひとつの式が、r を上げるにつれ 1点 → 2周期 → 4周期 → … と倍々に分岐し、
やがてカオスに至る様子を見ます。

- 蜘蛛の巣図（放物線と対角線の間を往復する軌道）をアニメーション表示
- 時系列グラフを併置、周期を自動判定して表示
- 分岐図は**ドラッグでズーム**でき、拡大しても同じ枝分かれの形が現れる自己相似を確認できる
- ファイゲンバウム定数 δ = 4.6692016… への収束を表で提示

### 21. 円の掛け算表
円周上に n 個の点を並べ、点 *k* と点 *k×m mod n* を結ぶだけ。
m=2 でカージオイド、m=3 でネフロイドが現れ、m が1増えるごとに尖点がひとつ増えます。

- n・m をスライダーで調整、m を連続的に動かすアニメーション
- 尖点の数を表示

### 22. ラングトンのアリ
白いマスなら右、黒いマスなら左に曲がり、そのマスの色を変えて1歩進む。それだけの規則で、
約1万歩の無秩序ののち<strong>突然「高速道路」を作って一直線に走り出します</strong>。一般には未証明の現象です。

- `L` と `R` の並びで多色ルール（チューリング的な蟻）を自由に指定でき、プリセットも用意
- 並進パターンを自動検出 — 原型 `RL` では既知のとおり**周期104・変位(2,2)**を検出します
- 位置だけでなく向きと彩色セル数の増分も一致することを条件にしているため、混沌期の偶然の直進を拾いません

### 23. ゴールドバッハのコメット — 未解決
「2より大きい偶数はすべて2つの素数の和で書ける」（1742年〜、未証明）。
偶数 n と表現数 g(n) を打点すると彗星形が現れ、n の小さな素因数ごとに筋に分かれます。

- 上限6万まで（篩＋素数ペア走査で数十ミリ秒）
- 3の倍数 / 5の倍数 / それ以外の3バンドに色分け（3の倍数が明確に上の筋になる）
- 偶数を入力するとその素数分解の組み合わせをすべて列挙

### 24. 連分数と向日葵
種を一定角度ずつ回して植えると、その角度が有理数で近似しにくいときだけ隙間なく詰まります。
黄金比の連分数は `[0; 1, 1, 1, …]` で最も近似しにくく、だから向日葵はその角度を使います。

- 回転角スライダーと種数スライダー、黄金比 / 1/√2 / 1/π / 1/e / π−3 / 有理数のプリセット
- 連分数展開と収束分数の表（黄金比ではフィボナッチ数列が現れる）
- 最小種間距離を充填度の指標として算出 — 黄金比 1.546 に対し 1/2 は 0.038

### 25. ゼータ零点と素数計数
素数べきで跳ぶ階段関数 ψ(x) は、なめらかな直線に零点ひとつにつき波をひとつ足すと再現できる —
リーマンの明示公式です。零点を足すたびに直線が階段に変わっていきます。

- 零点0〜50個をスライダー / アニメーションで追加
- RMS誤差が着実に減る様子を提示（最大誤差はジャンプ上のギブス現象に張り付くため、その旨も明記）
- 使用している零点50個は、Riemann–Siegel の Z 関数（Dirichlet η 級数 + Borwein 加速）の符号変化から
  **本プロジェクトで数値計算して確定**したもので、記憶からの引き写しではありません
  （古典的な最初の10個と 1×10⁻⁹ の精度で一致）

  （円周角・複素数平面。図を Tab でフォーカスし、動かす点を選んで矢印キー）

## 開発

```bash
npm install
npm run dev       # 開発サーバー起動
npm run build     # 本番ビルド
npm run preview   # ビルド結果をプレビュー
npm test          # 検証スクリプトをすべて実行
```

`main` ブランチへの push で GitHub Pages に自動デプロイされます（`.github/workflows/deploy.yml`）。
デプロイの前に `npm test` が走り、失敗すればデプロイされません。
ブランチと Pull Request では `.github/workflows/checks.yml` が同じ検証を実行します。

### 検証スクリプト

図や数値が正しいことを、実装とは別に確かめるためのものです。
手で計算できる値や厳密な等式と照合しており、実装が今返す値を写したものではありません。
`npm test`（= `node scripts/verify-all.mjs`）で全部まとめて実行できます。

```bash
node scripts/verify-core.mjs         # 分数・円の面積・割合と速さ・確率・中心極限定理
node scripts/verify-markup.mjs       # ビューが参照する id・aria の参照先・タブとビューの対応
node scripts/verify-solids.mjs       # 展開図が閉じて V−E+F=2 になるか
node scripts/verify-pythagoras.mjs   # 面積が全フレームで保たれるか
node scripts/verify-section.mjs      # 切り口の形・面積・体積比、2つの和がもとに戻るか
node scripts/verify-motion.mjs       # 重なりのグラフが区間ごとに2次式か、水量が保存されるか
node scripts/verify-conic.mjs        # 切り口が円錐と平面の上にあるか、焦点の性質を満たすか
node scripts/verify-zeta-zeros.mjs   # ゼータ零点の数値精度
```
