# math

コラッツ予想（3n+1問題）を可視化するインタラクティブなWebアプリです。

- 開始する整数を入力すると、偶数なら2で割り・奇数なら3倍して1を足す、を1に到達するまで繰り返す様子をアニメーションで表示します。
- 現在値・ステップ数をリアルタイムに表示し、完了時にステップ数・最大値・最大値到達ステップを確認できます。
- 複数の数列を比較表示（最大3系列）、対数スケール表示に対応しています。
- 「記録数列を探す」では、1から指定した上限までの整数のうち、ステップ数の記録を更新した開始値を探索してグラフ化します。
- ダーク/ライトモード対応。

## 開発

```bash
npm install
npm run dev       # 開発サーバー起動
npm run build     # 本番ビルド
npm run preview   # ビルド結果をプレビュー
```

`main` ブランチへの push で GitHub Pages に自動デプロイされます（`.github/workflows/deploy.yml`）。
