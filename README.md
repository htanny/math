# math

動かして確かめる数学のインタラクティブなWebアプリです。11のテーマをタブで切り替えます。

**公開URL: https://htanny.github.io/math/**

タブは2つのグループに分かれています。

- **学校数学** — 中学・高校で習う定理を、動かして納得できる形にしたもの
- **数の探検** — 未解決問題や、単純な規則から複雑な構造が現れる例

# 学校数学

### A. 円周角の定理（中3）
円周上の点 P をどこへドラッグしても、弦 AB を見込む角 ∠APB は変わりません。動かすこと自体が定理の実感になります。

- A・B・P すべてを円周上でドラッグ可能。P の軌跡を残して「どこでも同じ角」を可視化
- 中心角がつねに円周角の 2 倍であることを実測値で表示（P が劣弧側に回ると中心角は優角側に切り替わる）
- 「AB を直径にする」でタレスの定理（円周角 90°）
- 反対側の弧に点 Q を置くと、円に内接する四角形の対角の和が 180° になることを確認できる

### B. 単位円と三角関数（数学I・II）
単位円上を回る点の高さが、そのまま sin のグラフとして横に描かれていきます。円とグラフを点線で結んであるので、両者が同じものだと目で追えます。

- θ スライダーと1周アニメーション、sin / cos / tan の表示切替
- tan は x = 1 の接線上の線分として表示
- 0°・30°・45°・60°… のプリセットで暗記すべき厳密値を表示
- `y = A sin(B(x − C)) + D` のスライダー（振幅・周期・平行移動が文字とどう対応するか）

### C. 微分と積分（数学II・III）
微分＝接線の傾き、積分＝面積、そして「面積を微分すると元に戻る」を同じ関数の上で連動させています。

- 割線を h → 0 で接線に近づけるアニメーション。導関数のグラフを下段に同時表示
- 区分求積：短冊の数 n と高さの取り方（左端／中点／右端）を変えて、本当の面積への収束を数値で確認
- 面積関数 S(x) を下段に描き、その x = b での接線の傾きが上段の f(b) の高さと一致することを表示
  —— 微積分学の基本定理 S′(x) = f(x) の可視化

# 数の探検

### 1. コラッツ予想（3n+1問題）— 未解決
偶数なら2で割り、奇数なら3倍して1を足す、を1に到達するまで繰り返します。

- 数列が1ステップずつ進む様子をアニメーション表示（現在値・ステップ数をリアルタイム更新）
- 完了時にステップ数・最大値・最大値到達ステップを表示
- 最大3系列の比較表示、対数スケール切替、ホバーツールチップ
- 1〜指定上限のうちステップ数の記録を更新した開始値を棒グラフで探索

### 2. アリコット数列（カタラン・ディクソン予想）— 未解決
その数の「自分自身を除く約数の和」を繰り返します。1に到達するか、循環するか、
無限に大きくなり続けるか — 276 は2000項以上・200桁を超えてもなお決着していません。

- 終わり方を自動判定: 1に到達 / 完全数（1周期）/ 友愛数（2周期）/ 社交数（3周期以上）/ 未決着
- 循環に入った場合はその循環を表示（例: `220 → 284 → 220`）
- 1〜指定上限の各整数を「行き着く先」で分類して集計
- 値が 10<sup>12</sup> を超えた場合・260ステップに達した場合は打ち切り、その旨を明示

### 3. ロジスティック写像
`x → r·x(1−x)` というひとつの式が、r を上げるにつれ 1点 → 2周期 → 4周期 → … と倍々に分岐し、
やがてカオスに至る様子を見ます。

- 蜘蛛の巣図（放物線と対角線の間を往復する軌道）をアニメーション表示
- 時系列グラフを併置、周期を自動判定して表示
- 分岐図は**ドラッグでズーム**でき、拡大しても同じ枝分かれの形が現れる自己相似を確認できる
- ファイゲンバウム定数 δ = 4.6692016… への収束を表で提示

### 4. 円の掛け算表
円周上に n 個の点を並べ、点 *k* と点 *k×m mod n* を結ぶだけ。
m=2 でカージオイド、m=3 でネフロイドが現れ、m が1増えるごとに尖点がひとつ増えます。

- n・m をスライダーで調整、m を連続的に動かすアニメーション
- 尖点の数を表示

### 5. ラングトンのアリ
白いマスなら右、黒いマスなら左に曲がり、そのマスの色を変えて1歩進む。それだけの規則で、
約1万歩の無秩序ののち<strong>突然「高速道路」を作って一直線に走り出します</strong>。一般には未証明の現象です。

- `L` と `R` の並びで多色ルール（チューリング的な蟻）を自由に指定でき、プリセットも用意
- 並進パターンを自動検出 — 原型 `RL` では既知のとおり**周期104・変位(2,2)**を検出します
- 位置だけでなく向きと彩色セル数の増分も一致することを条件にしているため、混沌期の偶然の直進を拾いません

### 6. ゴールドバッハのコメット — 未解決
「2より大きい偶数はすべて2つの素数の和で書ける」（1742年〜、未証明）。
偶数 n と表現数 g(n) を打点すると彗星形が現れ、n の小さな素因数ごとに筋に分かれます。

- 上限6万まで（篩＋素数ペア走査で数十ミリ秒）
- 3の倍数 / 5の倍数 / それ以外の3バンドに色分け（3の倍数が明確に上の筋になる）
- 偶数を入力するとその素数分解の組み合わせをすべて列挙

### 7. 連分数と向日葵
種を一定角度ずつ回して植えると、その角度が有理数で近似しにくいときだけ隙間なく詰まります。
黄金比の連分数は `[0; 1, 1, 1, …]` で最も近似しにくく、だから向日葵はその角度を使います。

- 回転角スライダーと種数スライダー、黄金比 / 1/√2 / 1/π / 1/e / π−3 / 有理数のプリセット
- 連分数展開と収束分数の表（黄金比ではフィボナッチ数列が現れる）
- 最小種間距離を充填度の指標として算出 — 黄金比 1.546 に対し 1/2 は 0.038

### 8. ゼータ零点と素数計数
素数べきで跳ぶ階段関数 ψ(x) は、なめらかな直線に零点ひとつにつき波をひとつ足すと再現できる —
リーマンの明示公式です。零点を足すたびに直線が階段に変わっていきます。

- 零点0〜50個をスライダー / アニメーションで追加
- RMS誤差が着実に減る様子を提示（最大誤差はジャンプ上のギブス現象に張り付くため、その旨も明記）
- 使用している零点50個は、Riemann–Siegel の Z 関数（Dirichlet η 級数 + Borwein 加速）の符号変化から
  **本プロジェクトで数値計算して確定**したもので、記憶からの引き写しではありません
  （古典的な最初の10個と 1×10⁻⁹ の精度で一致）

## その他

- ライト / ダークモード対応（システム設定に追従、手動切替も可能）
- 外部チャートライブラリ不使用（Canvas 2D で自前描画）
- タブの状態は URL のハッシュ（`#calculus`・`#logistic` など）に反映されます

## 開発

```bash
npm install
npm run dev       # 開発サーバー起動
npm run build     # 本番ビルド
npm run preview   # ビルド結果をプレビュー
```

`main` ブランチへの push で GitHub Pages に自動デプロイされます（`.github/workflows/deploy.yml`）。
