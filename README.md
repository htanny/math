# math

単純な規則から複雑な振る舞いが生まれる数学を、アニメーションとグラフで探索するインタラクティブなWebアプリです。
4つのテーマをタブで切り替えます。

**公開URL: https://htanny.github.io/math/**

## 収録テーマ

### 1. コラッツ予想（3n+1問題）— 未解決
偶数なら2で割り、奇数なら3倍して1を足す、を1に到達するまで繰り返します。

- 数列が1ステップずつ進む様子をアニメーション表示（現在値・ステップ数をリアルタイム更新）
- 完了時にステップ数・最大値・最大値到達ステップを表示
- 最大3系列の比較表示、対数スケール切替、ホバーツールチップ
- 1〜指定上限のうちステップ数の記録を更新した開始値を棒グラフで探索

### 2. アリコット数列（カタラン・ディクソン予想）— 未解決
その数の「自分自身を除く約数の和」を繰り返します。1に到達するか、循環するか、
無限に大きくなり続けるか — 276 は2000項以上・200桁を超えてもなお決着していません。

- 終わり方を自動判定: 1に到達 / 完全数（1周期）/ 友愛数（2周期）/ 社交数（3周期以上）/ 未決着
- 循環に入った場合はその循環を表示（例: `220 → 284 → 220`）
- 1〜指定上限の各整数を「行き着く先」で分類して集計
- 値が 10<sup>12</sup> を超えた場合・260ステップに達した場合は打ち切り、その旨を明示

### 3. ロジスティック写像
`x → r·x(1−x)` というひとつの式が、r を上げるにつれ 1点 → 2周期 → 4周期 → … と倍々に分岐し、
やがてカオスに至る様子を見ます。

- 蜘蛛の巣図（放物線と対角線の間を往復する軌道）をアニメーション表示
- 時系列グラフを併置、周期を自動判定して表示
- 分岐図は**ドラッグでズーム**でき、拡大しても同じ枝分かれの形が現れる自己相似を確認できる
- ファイゲンバウム定数 δ = 4.6692016… への収束を表で提示

### 4. 円の掛け算表
円周上に n 個の点を並べ、点 *k* と点 *k×m mod n* を結ぶだけ。
m=2 でカージオイド、m=3 でネフロイドが現れ、m が1増えるごとに尖点がひとつ増えます。

- n・m をスライダーで調整、m を連続的に動かすアニメーション
- 尖点の数を表示

## その他

- ライト / ダークモード対応（システム設定に追従、手動切替も可能）
- 外部チャートライブラリ不使用（Canvas 2D で自前描画）
- タブの状態は URL のハッシュ（`#logistic` など）に反映されます

## 開発

```bash
npm install
npm run dev       # 開発サーバー起動
npm run build     # 本番ビルド
npm run preview   # ビルド結果をプレビュー
```

`main` ブランチへの push で GitHub Pages に自動デプロイされます（`.github/workflows/deploy.yml`）。
